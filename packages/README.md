# Общий код

Здесь лежит код, который используют несколько программ из [`apps/`](../apps/README.md). Пока общего кода нет.

Пример того, что может сюда попасть:

```
packages/
└── core/              ← модели и расчёты «Системы 168»
    ├── README.md
    └── src/           ← профиль человека, роли, недельный бюджет 168 часов,
                          формула дня 1 + 3 + 3 + 1, расчёт буфера и времени сна
```

## Правила

1. **Сюда переносится только то, что реально нужно двум и более программам.** Пока код нужен одной программе, он живёт в её папке.
2. **У каждого пакета свой README и файл зависимостей,** как у программ.
3. **Пакет не зависит от программ.** Программы подключают пакеты, а не наоборот.
4. **Изменение пакета проверяется вместе с программами, которые его используют.** Это главное преимущество одного репозитория: правка общей модели и всех её пользователей делается одним Pull Request.
5. **Если пакет понадобится проектам вне MyLife,** его можно вынести в отдельный репозиторий вместе с историей (`git subtree split --prefix=packages/<имя>`) и публиковать как библиотеку.
