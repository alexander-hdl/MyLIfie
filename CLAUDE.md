# MyLife — правила репозитория

Монорепозиторий. Проект о планировании дня по «Системе 168» (см. `docs/REPORT.md`).

## Структура

- `docs/` — исследования и отчёты на русском. `docs/REPORT.md` — основной отчёт, `docs/research/` — исходные исследовательские записки, `docs/MINDMAP.md` и `docs/mindmap.html` — ментальная карта.
- `apps/<имя>/` — отдельные программы. Правила — в `apps/README.md`.
- `packages/<имя>/` — общий код для нескольких программ. Правила — в `packages/README.md`.

## Соглашения

- Документация и пользовательские тексты пишутся на русском.
- Программы не импортируют код друг друга; общее выносится в `packages/`.
- У каждой программы и пакета свой README и файл зависимостей.
- Ветки: `feat/<программа>-<суть>`, `fix/...`, `docs/...`. Теги: `<программа>-vX.Y.Z`.
- Изменения попадают в `main` через Pull Request.
- Секреты не коммитятся: `.env` в `.gitignore`, в репозиторий кладётся `.env.example`.
- В `docs/` оценки доказательности следуют шкале A/B/C из раздела 1 `docs/REPORT.md`: методика, которую не проверяли целиком, получает C с указанием уровня механизма.
