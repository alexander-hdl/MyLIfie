## Система 168 в двух словах

1. **Профиль** — режим работы, хронотип, потребность в структуре, подотчётность, социальная энергия, особенности внимания.
2. **Фундамент** — сон от подъёма назад, якоря детей, минимум движения: эти блоки не двигаются.
3. **Смысл** — роли, ценности, 2–4 цели на квартал.
4. **Неделя** — 168 часов, «большие камни» по ролям в календарь первыми, недельный обзор и семейное совещание.
5. **День** — скелет по энергии (пик → спад → восстановление → закрытие → семья), формула «1 + 3 + 3 + 1», буфер 20–40 %.
6. **Исполнение** — техника фокуса под профиль, «если–то», пакетирование, заметки возобновления.
7. **Обратная связь** — день, неделя, месяц, квартал.
